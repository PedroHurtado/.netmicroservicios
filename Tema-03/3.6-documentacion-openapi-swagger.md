## ¿Qué es OpenAPI / Swagger?

**OpenAPI** (antes **Swagger**) es un estándar abierto para describir APIs REST de forma machine-readable.

### Beneficios

✅ **Documentación automática:** Se genera del código  
✅ **Testeo interactivo:** Swagger UI para probar endpoints sin Postman  
✅ **Generación de clientes:** Herramientas pueden generar SDKs  
✅ **Contrato API:** Punto único de verdad para consumers  
✅ **Monitoreo:** Herramientas como SonarQube la usan para análisis

## Setup de Swagger en ASP.NET Core

### Instalación

```bash
dotnet add package Swashbuckle.AspNetCore
```

### Configuración en Program.cs

```csharp
var builder = WebApplicationBuilder.CreateBuilder(args);

// Servicios
builder.Services.AddControllers();

// Swagger
builder.Services.AddSwaggerGen(options =>
{
    options.SwaggerDoc("v1", new Microsoft.OpenApi.Models.OpenApiInfo
    {
        Version = "v1",
        Title = "Catalog.API",
        Description = "Microservicio de catálogo para ShopMicro",
        Contact = new Microsoft.OpenApi.Models.OpenApiContact
        {
            Name = "ShopMicro Team",
            Email = "support@shopmicro.local",
            Url = new Uri("https://shopmicro.local")
        },
        License = new Microsoft.OpenApi.Models.OpenApiLicense
        {
            Name = "MIT",
            Url = new Uri("https://opensource.org/licenses/MIT")
        }
    });

    // Incluir comentarios XML
    var xmlFile = "Catalog.API.xml";
    var xmlPath = Path.Combine(AppContext.BaseDirectory, xmlFile);
    if (File.Exists(xmlPath))
        options.IncludeXmlComments(xmlPath);

    // Schemes (HTTP, HTTPS)
    options.AddSecurityDefinition("Bearer", new Microsoft.OpenApi.Models.OpenApiSecurityScheme
    {
        Type = Microsoft.OpenApi.Models.SecuritySchemeType.Http,
        Scheme = "bearer",
        BearerFormat = "JWT",
        Description = "JWT Authorization header using the Bearer scheme."
    });

    options.AddSecurityRequirement(new Microsoft.OpenApi.Models.OpenApiSecurityRequirement
    {
        {
            new Microsoft.OpenApi.Models.OpenApiSecurityScheme
            {
                Reference = new Microsoft.OpenApi.Models.OpenApiReference
                {
                    Type = Microsoft.OpenApi.Models.ReferenceType.SecurityScheme,
                    Id = "Bearer"
                }
            },
            new string[] {}
        }
    });
});

var app = builder.Build();

if (app.Environment.IsDevelopment())
{
    app.UseSwagger();
    app.UseSwaggerUI(options =>
    {
        options.SwaggerEndpoint("/swagger/v1/swagger.json", "Catalog.API v1");
        options.RoutePrefix = string.Empty;  // Swagger en raíz
    });
}

app.UseHttpsRedirection();
app.UseAuthorization();
app.MapControllers();

app.Run();
```

## Documentar endpoints con atributos

### Ejemplo: CreateProduct

```csharp
namespace Catalog.API.Features.Products.Create;

using Microsoft.AspNetCore.Mvc;
using MediatR;

[ApiController]
[Route("api/v1/products")]
public class CreateProductEndpoint : ControllerBase
{
    private readonly IMediator _mediator;

    public CreateProductEndpoint(IMediator mediator)
    {
        _mediator = mediator;
    }

    /// <summary>
    /// Crea un nuevo producto en el catálogo.
    /// </summary>
    /// <param name="request">Datos del producto a crear</param>
    /// <param name="cancellationToken">Token de cancelación</param>
    /// <returns>Producto creado</returns>
    /// <response code="201">Producto creado exitosamente</response>
    /// <response code="400">Datos inválidos o incompletos</response>
    /// <response code="422">Error de validación</response>
    /// <response code="409">Conflicto (ej: producto duplicado)</response>
    /// <response code="500">Error interno del servidor</response>
    [HttpPost]
    [Produces("application/json")]
    [Consumes("application/json")]
    [ProduceResponseType(typeof(CreateProductResponse), StatusCodes.Status201Created)]
    [ProduceResponseType(typeof(ProblemDetails), StatusCodes.Status400BadRequest)]
    [ProduceResponseType(typeof(ProblemDetails), StatusCodes.Status422UnprocessableEntity)]
    [ProduceResponseType(typeof(ProblemDetails), StatusCodes.Status409Conflict)]
    [ProduceResponseType(typeof(ProblemDetails), StatusCodes.Status500InternalServerError)]
    public async Task<IActionResult> Create(
        [FromBody] CreateProductRequest request,
        CancellationToken cancellationToken = default)
    {
        var command = request.ToCommand();
        var response = await _mediator.Send(command, cancellationToken);

        return CreatedAtAction(nameof(GetProductById), new { id = response.Id }, response);
    }
}

/// <summary>
/// Respuesta al crear un producto.
/// </summary>
public record CreateProductResponse(
    /// <summary>Identificador único del producto</summary>
    Guid Id,

    /// <summary>Precio del producto</summary>
    decimal Price
);

/// <summary>
/// Solicitud para crear un producto.
/// </summary>
public record CreateProductRequest(
    /// <summary>Nombre del producto (3-100 caracteres)</summary>
    string Name,

    /// <summary>Descripción detallada (mínimo 10 caracteres)</summary>
    string Description,

    /// <summary>Precio en USD (> 0)</summary>
    decimal Price,

    /// <summary>Cantidad en stock (>= 0)</summary>
    int Stock
);
```

```csharp
namespace Catalog.API.Features.Products.Domain;

/// <summary>
/// Entidad de dominio que representa un producto en el catálogo.
/// </summary>
public class Product
{
    /// <summary>
    /// Identificador único del producto.
    /// </summary>
    public Guid Id { get; private set; }

    /// <summary>
    /// Nombre del producto (máximo 100 caracteres).
    /// </summary>
    public string Name { get; private set; }

    /// <summary>
    /// Descripción detallada del producto.
    /// </summary>
    public string Description { get; private set; }

    /// <summary>
    /// Precio del producto en USD.
    /// </summary>
    public decimal Price { get; private set; }

    /// <summary>
    /// Cantidad disponible en stock.
    /// </summary>
    public int Stock { get; private set; }

    /// <summary>
    /// Fecha de creación del producto (UTC).
    /// </summary>
    public DateTime CreatedAt { get; private set; }

    /// <summary>
    /// Fecha de última actualización (UTC, nulable).
    /// </summary>
    public DateTime? UpdatedAt { get; private set; }

    /// <summary>
    /// Crea una nueva instancia de Product.
    /// </summary>
    /// <param name="id">ID único del producto</param>
    /// <param name="name">Nombre del producto</param>
    /// <param name="description">Descripción</param>
    /// <param name="price">Precio en USD</param>
    /// <param name="stock">Cantidad inicial en stock</param>
    /// <returns>Nueva instancia de Product</returns>
    public static Product Create(
        Guid id,
        string name,
        string description,
        decimal price,
        int stock)
    {
        return new Product
        {
            Id = id,
            Name = name,
            Description = description,
            Price = price,
            Stock = stock,
            CreatedAt = DateTime.UtcNow
        };
    }

    /// <summary>
    /// Actualiza los datos del producto.
    /// </summary>
    /// <param name="name">Nuevo nombre</param>
    /// <param name="description">Nueva descripción</param>
    /// <param name="price">Nuevo precio</param>
    /// <param name="stock">Nuevo stock</param>
    public void Update(string name, string description, decimal price, int stock)
    {
        Name = name;
        Description = description;
        Price = price;
        Stock = stock;
        UpdatedAt = DateTime.UtcNow;
    }
}
```

## Ejemplo completo: Todos los CRUD documentados

```csharp
namespace Catalog.API.Features.Products;

using Microsoft.AspNetCore.Mvc;
using MediatR;

/// <summary>
/// Controlador para gestionar productos del catálogo.
/// </summary>
[ApiController]
[Route("api/v1/products")]
[Produces("application/json")]
[Consumes("application/json")]
public class ProductsController : ControllerBase
{
    private readonly IMediator _mediator;

    public ProductsController(IMediator mediator)
    {
        _mediator = mediator;
    }

    /// <summary>
    /// Obtiene la lista de productos con paginación.
    /// </summary>
    /// <param name="skip">Número de productos a saltar (default: 0)</param>
    /// <param name="take">Número de productos a devolver (default: 10, máximo: 100)</param>
    /// <param name="cancellationToken">Token de cancelación</param>
    /// <returns>Lista paginada de productos</returns>
    /// <response code="200">Lista de productos obtenida</response>
    /// <response code="400">Parámetros de paginación inválidos</response>
    [HttpGet]
    [ProduceResponseType(typeof(ListProductsResponse), StatusCodes.Status200OK)]
    [ProduceResponseType(typeof(ProblemDetails), StatusCodes.Status400BadRequest)]
    public async Task<IActionResult> List(
        [FromQuery(Name = "skip")] int skip = 0,
        [FromQuery(Name = "take")] int take = 10,
        CancellationToken cancellationToken = default)
    {
        var query = new ListProducts.Query(skip, take);
        var response = await _mediator.Send(query, cancellationToken);
        return Ok(response);
    }

    /// <summary>
    /// Obtiene un producto específico por su ID.
    /// </summary>
    /// <param name="id">Identificador único del producto (GUID)</param>
    /// <param name="cancellationToken">Token de cancelación</param>
    /// <returns>Datos del producto</returns>
    /// <response code="200">Producto encontrado</response>
    /// <response code="404">Producto no encontrado</response>
    [HttpGet("{id:guid}")]
    [ProduceResponseType(typeof(ProductResponse), StatusCodes.Status200OK)]
    [ProduceResponseType(typeof(ProblemDetails), StatusCodes.Status404NotFound)]
    public async Task<IActionResult> GetById(
        [FromRoute] Guid id,
        CancellationToken cancellationToken = default)
    {
        var query = new GetProductById.Query(id);
        var response = await _mediator.Send(query, cancellationToken);
        return Ok(response);
    }

    /// <summary>
    /// Crea un nuevo producto en el catálogo.
    /// </summary>
    /// <param name="request">Datos del producto</param>
    /// <param name="cancellationToken">Token de cancelación</param>
    /// <returns>Producto creado</returns>
    /// <response code="201">Producto creado exitosamente</response>
    /// <response code="400">Datos inválidos</response>
    /// <response code="422">Errores de validación</response>
    /// <response code="409">Producto duplicado</response>
    [HttpPost]
    [ProduceResponseType(typeof(CreateProductResponse), StatusCodes.Status201Created)]
    [ProduceResponseType(typeof(ProblemDetails), StatusCodes.Status400BadRequest)]
    [ProduceResponseType(typeof(ProblemDetails), StatusCodes.Status422UnprocessableEntity)]
    [ProduceResponseType(typeof(ProblemDetails), StatusCodes.Status409Conflict)]
    public async Task<IActionResult> Create(
        [FromBody] CreateProductRequest request,
        CancellationToken cancellationToken = default)
    {
        var command = request.ToCommand();
        var response = await _mediator.Send(command, cancellationToken);
        return CreatedAtAction(nameof(GetById), new { id = response.Id }, response);
    }

    /// <summary>
    /// Actualiza completamente un producto (PUT).
    /// </summary>
    /// <param name="id">ID del producto a actualizar</param>
    /// <param name="request">Nuevos datos</param>
    /// <param name="cancellationToken">Token de cancelación</param>
    /// <returns>Sin contenido</returns>
    /// <response code="204">Producto actualizado</response>
    /// <response code="404">Producto no encontrado</response>
    /// <response code="422">Errores de validación</response>
    [HttpPut("{id:guid}")]
    [ProduceResponseType(StatusCodes.Status204NoContent)]
    [ProduceResponseType(typeof(ProblemDetails), StatusCodes.Status404NotFound)]
    [ProduceResponseType(typeof(ProblemDetails), StatusCodes.Status422UnprocessableEntity)]
    public async Task<IActionResult> Update(
        [FromRoute] Guid id,
        [FromBody] UpdateProductRequest request,
        CancellationToken cancellationToken = default)
    {
        var command = request.ToCommand(id);
        await _mediator.Send(command, cancellationToken);
        return NoContent();
    }

    /// <summary>
    /// Actualiza parcialmente un producto (PATCH).
    /// </summary>
    /// <param name="id">ID del producto</param>
    /// <param name="request">Campos a actualizar</param>
    /// <param name="cancellationToken">Token de cancelación</param>
    /// <returns>Sin contenido</returns>
    /// <response code="204">Producto actualizado</response>
    /// <response code="404">Producto no encontrado</response>
    [HttpPatch("{id:guid}")]
    [ProduceResponseType(StatusCodes.Status204NoContent)]
    [ProduceResponseType(typeof(ProblemDetails), StatusCodes.Status404NotFound)]
    public async Task<IActionResult> PartialUpdate(
        [FromRoute] Guid id,
        [FromBody] PatchProductRequest request,
        CancellationToken cancellationToken = default)
    {
        var command = request.ToCommand(id);
        await _mediator.Send(command, cancellationToken);
        return NoContent();
    }

    /// <summary>
    /// Elimina un producto del catálogo.
    /// </summary>
    /// <param name="id">ID del producto a eliminar</param>
    /// <param name="cancellationToken">Token de cancelación</param>
    /// <returns>Sin contenido</returns>
    /// <response code="204">Producto eliminado</response>
    /// <response code="404">Producto no encontrado</response>
    [HttpDelete("{id:guid}")]
    [ProduceResponseType(StatusCodes.Status204NoContent)]
    [ProduceResponseType(typeof(ProblemDetails), StatusCodes.Status404NotFound)]
    public async Task<IActionResult> Delete(
        [FromRoute] Guid id,
        CancellationToken cancellationToken = default)
    {
        var command = new DeleteProduct.Command(id);
        await _mediator.Send(command, cancellationToken);
        return NoContent();
    }
}

/// <summary>Respuesta al obtener un producto</summary>
public record ProductResponse(Guid Id, string Name, string Description, decimal Price, int Stock, DateTime CreatedAt, DateTime? UpdatedAt);

/// <summary>Respuesta al crear un producto</summary>
public record CreateProductResponse(Guid Id, decimal Price);

/// <summary>Solicitud para crear producto</summary>
public record CreateProductRequest(string Name, string Description, decimal Price, int Stock);

/// <summary>Solicitud para actualizar completamente un producto</summary>
public record UpdateProductRequest(string Name, string Description, decimal Price, int Stock);

/// <summary>Solicitud para actualizar parcialmente un producto</summary>
public record PatchProductRequest(string? Name, string? Description, decimal? Price, int? Stock);
```

## Filtros de Swagger personalizados

### Agrupar endpoints por tags

```csharp
[HttpGet]
[Tags("Products")]
public async Task<IActionResult> List(...)

[HttpPost]
[Tags("Products")]
public async Task<IActionResult> Create(...)
```

### Marcar operaciones como deprecadas

```csharp
[HttpGet("old-endpoint")]
[Obsolete("Use /api/v2/products en su lugar")]
[ProduceResponseType(StatusCodes.Status410Gone)]
public async Task<IActionResult> OldEndpoint(...)
```

## Autenticación en Swagger

**Configurar JWT Bearer:**

```csharp
options.AddSecurityDefinition("Bearer", new OpenApiSecurityScheme
{
    Type = SecuritySchemeType.Http,
    Scheme = "bearer",
    BearerFormat = "JWT",
    Description = "Introduce un token JWT válido"
});

options.AddSecurityRequirement(new OpenApiSecurityRequirement
{
    {
        new OpenApiSecurityScheme
        {
            Reference = new OpenApiReference { Type = ReferenceType.SecurityScheme, Id = "Bearer" }
        },
        new string[] {}
    }
});
```

Luego en Swagger UI, habrá un botón "Authorize" para pegar el token.

## Generar clientes desde Swagger

Herramientas como **AutoRest**, **OpenAPI Generator** pueden generar clientes para C#, JavaScript, Python, etc.

### Desde línea de comandos

```bash
# Generar cliente C#
openapi-generator-cli generate -i http://localhost:5000/swagger/v1/swagger.json \
  -g csharp -o ./GeneratedClient

# Generar SDK TypeScript
openapi-generator-cli generate -i http://localhost:5000/swagger/v1/swagger.json \
  -g typescript-axios -o ./GeneratedSdk
```

## Puntos clave

- **OpenAPI:** Estándar abierto, machine-readable
- **Swagger UI:** Interfaz interactiva para testear (development)
- **Comentarios XML:** Documentación en el código
- **ProduceResponseType:** Declara qué tipos de respuesta devuelve
- **Tags:** Organiza endpoints en Swagger UI
- **JWT Bearer:** Permite autenticarse en Swagger UI
- **Versionado:** `/api/v1/` en la URL del endpoint
- **Documentación viva:** Sincronizada automáticamente con el código
