## ¿Por qué FluentValidation?

### El problema: Validación con Data Annotations

```csharp
public record CreateProductRequest(
    [Required(ErrorMessage = "El nombre es obligatorio")]
    [StringLength(100, MinimumLength = 3, ErrorMessage = "El nombre debe tener entre 3 y 100 caracteres")]
    string Name,

    [Required(ErrorMessage = "El precio es obligatorio")]
    [Range(0.01, double.MaxValue, ErrorMessage = "El precio debe ser mayor a 0")]
    decimal Price,

    [Range(0, int.MaxValue, ErrorMessage = "El stock no puede ser negativo")]
    int Stock
);
```

**Problemas:**
1. Lógica de validación acoplada al DTO
2. Difícil de reutilizar
3. No permite validaciones complejas (cross-field)
4. Difícil de testear
5. Mensajes de error en atributos (mezcla de responsabilidades)

### Ventajas de FluentValidation

✅ Validación desacoplada del modelo  
✅ API fluida y legible  
✅ Soporta validaciones asincrónicas  
✅ Validaciones complejas y cross-field  
✅ Reutilizable en múltiples contextos  
✅ Fácil de testear  
✅ Mensajes de error localizables

## Validador básico

### CreateProductValidator.cs

```csharp
namespace Catalog.API.Features.Products.Create;

using FluentValidation;

public class CreateProductValidator : AbstractValidator<CreateProduct.Command>
{
    public CreateProductValidator()
    {
        RuleFor(x => x.Name)
            .NotEmpty().WithMessage("El nombre es obligatorio")
            .MaximumLength(100).WithMessage("El nombre no puede exceder 100 caracteres")
            .MinimumLength(3).WithMessage("El nombre debe tener al menos 3 caracteres");

        RuleFor(x => x.Description)
            .NotEmpty().WithMessage("La descripción es obligatoria")
            .MinimumLength(10).WithMessage("La descripción debe tener al menos 10 caracteres");

        RuleFor(x => x.Price)
            .GreaterThan(0).WithMessage("El precio debe ser mayor a 0")
            .LessThanOrEqualTo(999999.99m).WithMessage("El precio no puede exceder 999999.99");

        RuleFor(x => x.Stock)
            .GreaterThanOrEqualTo(0).WithMessage("El stock no puede ser negativo")
            .LessThanOrEqualTo(999999).WithMessage("El stock no puede exceder 999999");
    }
}
```

## Validaciones complejas

### Validaciones condicionales

```csharp
public class UpdateProductValidator : AbstractValidator<UpdateProduct.Command>
{
    public UpdateProductValidator()
    {
        RuleFor(x => x.Name)
            .NotEmpty()
            .When(x => !string.IsNullOrEmpty(x.Name))
            .WithMessage("Si proporciona un nombre, no puede estar vacío");

        RuleFor(x => x.Price)
            .GreaterThan(0)
            .When(x => x.Price.HasValue)
            .WithMessage("Si actualiza el precio, debe ser mayor a 0");
    }
}
```

### Validaciones cross-field

```csharp
public class CreateOrderValidator : AbstractValidator<CreateOrder.Command>
{
    public CreateOrderValidator()
    {
        RuleFor(x => x)
            .Must(BeValidOrderDates)
            .WithMessage("La fecha de entrega debe ser posterior a la fecha de creación");

        RuleFor(x => x.Items)
            .NotEmpty().WithMessage("La orden debe contener al menos un artículo")
            .Must(HaveValidQuantities).WithMessage("Todos los artículos deben tener cantidad > 0");
    }

    private static bool BeValidOrderDates(CreateOrder.Command command) =>
        command.DeliveryDate > DateTime.UtcNow.AddDays(1);

    private static bool HaveValidQuantities(List<OrderItem> items) =>
        items.All(i => i.Quantity > 0);
}
```

### Validaciones asincrónicas

```csharp
public class CreateProductValidator : AbstractValidator<CreateProduct.Command>
{
    private readonly IProductRepository _repository;

    public CreateProductValidator(IProductRepository repository)
    {
        _repository = repository;

        RuleFor(x => x.Name)
            .NotEmpty()
            .MustAsync(BeUniqueProductName)
            .WithMessage("Ya existe un producto con ese nombre");
    }

    private async Task<bool> BeUniqueProductName(string name, CancellationToken cancellationToken)
    {
        // Simular búsqueda en BD
        var exists = await _repository.ExistsByNameAsync(name, cancellationToken);
        return !exists;
    }
}
```

## Integración con MediatR

### Pipeline Behavior para validación automática

```csharp
namespace Catalog.API.Core.Behaviors;

using MediatR;
using FluentValidation;

public class ValidationBehavior<TRequest, TResponse> : IPipelineBehavior<TRequest, TResponse>
    where TRequest : notnull, IRequest<TResponse>
{
    private readonly IEnumerable<IValidator<TRequest>> _validators;
    private readonly ILogger<ValidationBehavior<TRequest, TResponse>> _logger;

    public ValidationBehavior(
        IEnumerable<IValidator<TRequest>> validators,
        ILogger<ValidationBehavior<TRequest, TResponse>> logger)
    {
        _validators = validators;
        _logger = logger;
    }

    public async Task<TResponse> Handle(
        TRequest request,
        RequestHandlerDelegate<TResponse> next,
        CancellationToken cancellationToken)
    {
        var context = new ValidationContext<TRequest>(request);
        var validationResults = await Task.WhenAll(
            _validators.Select(v => v.ValidateAsync(context, cancellationToken))
        );

        var failures = validationResults
            .Where(result => !result.IsValid)
            .SelectMany(result => result.Errors)
            .ToList();

        if (failures.Any())
        {
            _logger.LogWarning("Validation failed for {RequestName} with {ErrorCount} errors",
                typeof(TRequest).Name, failures.Count);

            throw new ValidationException(failures);
        }

        return await next();
    }
}
```

**Registrar en Program.cs:**

```csharp
builder.Services.AddMediatR(typeof(Program));
builder.Services.AddValidatorsFromAssembly(typeof(Program).Assembly);
builder.Services.AddTransient(typeof(IPipelineBehavior<,>), typeof(ValidationBehavior<,>));
```

## Manejo de excepciones de validación

### ExceptionHandler para ValidationException

```csharp
namespace Catalog.API.Infrastructure.Middleware;

using FluentValidation;
using Microsoft.AspNetCore.Mvc;

public class ValidationExceptionHandler
{
    private readonly RequestDelegate _next;

    public ValidationExceptionHandler(RequestDelegate next)
    {
        _next = next;
    }

    public async Task InvokeAsync(HttpContext context)
    {
        try
        {
            await _next(context);
        }
        catch (ValidationException ex)
        {
            context.Response.StatusCode = StatusCodes.Status422UnprocessableEntity;
            context.Response.ContentType = "application/json";

            var problemDetails = new ProblemDetails
            {
                Type = "https://api.shopmicro.local/errors/validation-error",
                Title = "Validation Error",
                Status = StatusCodes.Status422UnprocessableEntity,
                Detail = "One or more validation errors occurred.",
                Instance = context.Request.Path,
            };

            var errors = ex.Errors
                .GroupBy(x => x.PropertyName)
                .ToDictionary(
                    g => g.Key,
                    g => g.Select(x => x.ErrorMessage).ToArray()
                );

            var response = new
            {
                problemDetails.Type,
                problemDetails.Title,
                problemDetails.Status,
                problemDetails.Detail,
                problemDetails.Instance,
                Errors = errors
            };

            await context.Response.WriteAsJsonAsync(response);
        }
    }
}
```

**Registrar en Program.cs:**

```csharp
app.UseMiddleware<ValidationExceptionHandler>();
```

## Validadores reutilizables

### Custom Validators

```csharp
namespace Catalog.API.Core.Validators;

using FluentValidation;

public static class CustomValidators
{
    public static IRuleBuilderOptions<T, string> BeValidSkuFormat<T>(
        this IRuleBuilder<T, string> ruleBuilder)
    {
        return ruleBuilder
            .Matches(@"^[A-Z]{3}-\d{4}$")
            .WithMessage("El SKU debe tener formato: ABC-1234 (3 letras mayúsculas, guión, 4 dígitos)");
    }

    public static IRuleBuilderOptions<T, decimal> BeValidPrice<T>(
        this IRuleBuilder<T, decimal> ruleBuilder)
    {
        return ruleBuilder
            .GreaterThan(0)
            .WithMessage("El precio debe ser mayor a 0")
            .LessThanOrEqualTo(999999.99m)
            .WithMessage("El precio no puede exceder 999999.99")
            .ScalePrecision(2, 8)
            .WithMessage("El precio no puede tener más de 2 decimales");
    }
}
```

**Usar:**

```csharp
public class CreateProductValidator : AbstractValidator<CreateProduct.Command>
{
    public CreateProductValidator()
    {
        RuleFor(x => x.Sku).BeValidSkuFormat();
        RuleFor(x => x.Price).BeValidPrice();
    }
}
```

## Ejemplo completo: Validador con reglas complejas

```csharp
namespace Catalog.API.Features.Products.Create;

using FluentValidation;

public class CreateProductValidator : AbstractValidator<CreateProduct.Command>
{
    private readonly IProductRepository _repository;
    private static readonly string[] AllowedCategories = { "Electronics", "Software", "Hardware" };

    public CreateProductValidator(IProductRepository repository)
    {
        _repository = repository;

        RuleFor(x => x.Name)
            .Cascade(CascadeMode.Stop)  // Detener en el primer error
            .NotEmpty().WithMessage("El nombre es obligatorio")
            .Length(3, 100).WithMessage("El nombre debe tener entre 3 y 100 caracteres")
            .Matches(@"^[a-zA-Z0-9\s\-]+$").WithMessage("El nombre solo puede contener letras, números, espacios y guiones")
            .MustAsync(BeUniqueProductName).WithMessage("Ya existe un producto con ese nombre");

        RuleFor(x => x.Description)
            .NotEmpty().WithMessage("La descripción es obligatoria")
            .MinimumLength(10).WithMessage("La descripción debe tener al menos 10 caracteres")
            .MaximumLength(500).WithMessage("La descripción no puede exceder 500 caracteres");

        RuleFor(x => x.Price)
            .NotEmpty()
            .GreaterThan(0).WithMessage("El precio debe ser mayor a 0")
            .LessThanOrEqualTo(999999.99m).WithMessage("El precio no puede exceder 999999.99")
            .ScalePrecision(2, 8).WithMessage("El precio no puede tener más de 2 decimales");

        RuleFor(x => x.Stock)
            .GreaterThanOrEqualTo(0).WithMessage("El stock no puede ser negativo")
            .LessThanOrEqualTo(999999).WithMessage("El stock no puede exceder 999999");

        // Regla condicional
        RuleFor(x => x.Price)
            .LessThan(100)
            .When(x => x.Stock < 10)
            .WithMessage("Productos con stock bajo deben tener precio menor a 100");
    }

    private async Task<bool> BeUniqueProductName(string name, CancellationToken cancellationToken)
    {
        var exists = await _repository.ExistsByNameAsync(name, cancellationToken);
        return !exists;
    }
}
```

## Testing de validadores

```csharp
using FluentValidation.TestHelper;
using Xunit;

public class CreateProductValidatorTests
{
    private readonly CreateProductValidator _validator;

    public CreateProductValidatorTests()
    {
        var repository = new MockProductRepository();
        _validator = new CreateProductValidator(repository);
    }

    [Fact]
    public void ShouldFailWhenNameIsEmpty()
    {
        var command = new CreateProduct.Command("", "Description", 99.99m, 10);
        var result = _validator.TestValidate(command);
        result.ShouldHaveValidationErrorFor(x => x.Name);
    }

    [Fact]
    public void ShouldFailWhenPriceIsZero()
    {
        var command = new CreateProduct.Command("Product", "Description", 0, 10);
        var result = _validator.TestValidate(command);
        result.ShouldHaveValidationErrorFor(x => x.Price)
            .WithErrorMessage("El precio debe ser mayor a 0");
    }

    [Fact]
    public void ShouldPassWhenDataIsValid()
    {
        var command = new CreateProduct.Command("Valid Product", "A valid description", 99.99m, 10);
        var result = _validator.TestValidate(command);
        result.ShouldNotHaveAnyValidationErrors();
    }
}
```

## Cascade Mode

Controla cuándo se detiene la validación:

```csharp
public class CreateProductValidator : AbstractValidator<CreateProduct.Command>
{
    public CreateProductValidator()
    {
        // Stop detiene en el primer error de la regla
        RuleFor(x => x.Name)
            .Cascade(CascadeMode.Stop)
            .NotEmpty()
            .Length(3, 100)
            .Matches(@"^[a-zA-Z0-9]+$");

        // Continue valida todas las reglas (default)
        RuleFor(x => x.Price)
            .Cascade(CascadeMode.Continue)
            .GreaterThan(0)
            .LessThanOrEqualTo(999999.99m);
    }
}
```

## Localización de mensajes

```csharp
namespace Catalog.API.Core.Localization;

using FluentValidation;

public class ValidationMessagesLocalizer
{
    public static void ConfigureLocalization()
    {
        ValidatorOptions.Global.ErrorMessageSource = new MessageSource();
    }

    private class MessageSource : ILanguageManager
    {
        private readonly Dictionary<string, string> _messages = new()
        {
            { "NotEmptyValidator", "El campo {PropertyName} es obligatorio" },
            { "LengthValidator", "El campo {PropertyName} debe tener entre {MinLength} y {MaxLength} caracteres" },
            { "GreaterThanValidator", "El campo {PropertyName} debe ser mayor a {ComparisonValue}" }
        };

        public string GetString(string key, System.Globalization.CultureInfo culture)
        {
            return _messages.TryGetValue(key, out var message) ? message : key;
        }
    }
}
```

## Puntos clave

- **FluentValidation:** Desacopla validaciones del modelo
- **Validadores asincróticos:** Para verificar unicidad en BD
- **Pipeline Behavior:** Inyecta validación automáticamente en MediatR
- **Validaciones complejas:** Soporta cross-field y condicionales
- **Reutilización:** Custom validators para reglas comunes
- **Testing:** Fácil de testear con `TestHelper`
- **Mensajes localizables:** Soporta i18n
- **Cascade Mode:** Controla cuándo detener validación
